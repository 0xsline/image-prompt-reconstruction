# 验证一次反推，而不是挑一张好图

只有用户需要评测或迭代共享指令时才读取本文。普通单图反推按根目录 `SKILL.md` 执行，不先读取案例答案。

## 运行前冻结

保存每张源图、SHA-256、来源与使用权限。按用途划分开发样本和留出样本，在查看新版本结果之前，确定可见事实、容差、要实际生图的样本和每版次数。

可见检查可包括主体数量与位置、画面占比、遮挡和前后关系，以及类别特征。绘画应检查笔触或平涂，不能只检查画中物体。主体外接框的面积不是像素分割面积，不与后者混用。bbox 写作归一化的左、上、右、下边界，并给出视觉估计容差。

只有所有子条件满足，才能将一条检查判为完整支持或通过。把多个条件合在一句检查里后，只满足其中一半也不能算通过。

## 执行与保留

反推执行器只看图片与固定的通用指令，不接收网页标题、原作者说明或冻结答案。保存每张首次英文，修改后的版本另存。比较不同指令时，反推模型和执行方式保持一致，工具辅助对话与裸 API 调用分别标注。

需要生图时，将完整英文原样发送给同一个生成模型，不发送源图，不加单图修饰词。保留每一次成功、失败和平台拒绝。模型不可用、配额不足或生成失败都写明，不换模型后继续使用旧名称。参考图生成属于不同实验。

记录实际返回的尺寸、质量、模型与可核实参数。种子未控制、尺寸或质量不同，不能把所有差异归因于指令。先选定图，再生成，不根据好坏换图或增加抽样次数。

## 分开判断文字和图片

文字状态：

| 状态 | 条件 |
|---|---|
| supported | 检查的全部子条件都明确覆盖，且没有矛盾 |
| partial | 只覆盖一部分，其余未说明 |
| omitted | 没有足够描述支持该条件 |
| contradicted | 至少有一项明确描述与源图冲突 |

实际生图状态：

| 状态 | 条件 |
|---|---|
| pass | 实际查看原图与生成图，全部子条件均符合冻结容差 |
| fail | 至少一个可见条件明确不符 |
| uncertain | 视觉估计跨越容差边界，或无法可靠判断 |
| not_generated | 没有生成图片，不计为通过或零分 |

每条保留证据、理由和适用时的测量估计。bbox 边界与面积分别判断，不能用一项通过抵消另一项失败。发现原始标注明显有误时记录标注问题，不为适应生成结果悄悄修改标准。

## 报告范围

分别报告独立图片数、描述份数、实际生图数、每种状态数量和评审者类型。标明 AI 视觉估计与人类专家标注的区别。公开网络图片可能已在训练数据中，不称为模型完全未见的图片。

本仓库公开案例为 12 张源图、12 份首次描述、12 张纯文生成图。48 条文字检查中 29 条完整支持、19 条部分覆盖。首批六张的 24 条生图检查中 17 条通过、7 条不通过；用户要求完整对比后，用已有英文补齐另外六张，对应 24 条检查中 13 条通过、9 条不通过、2 条不确定。合计 48 条生图检查：30 条通过、16 条不通过、2 条不确定，没有未生图样本。

补充批次沿用原先冻结的检查项，不是新的独立留出集。十二张均为 GPT Image 2、每张一次、无参考图；s18 返回 `low`，s26 返回 `high`，其余十张为 `medium`。质量由工具实际回执记录，未统一控制，不能将跨图差异全归因于提示词。补充图像由 AI 视觉代理对照原图与生成图进行非盲评，不是人工专家标注。

这些是有限检查项的结果，不是整图相似度、总体准确率或类别排名。首批室内与建筑虽然各通过 4 条限定条件，背景、布置与细部仍有变化。旧轮次或不同口径的分数不能直接比较。

## 迭代规则

只在开发集上修改共享指令，可以重复运行以观察波动。选定并冻结版本后再查看留出结果。如果继续依据留出结果调整，该批图片就成为开发样本，需要另一批未参与调试的图片验证。

对精确几何、数量、商品款式或笔触有严格要求时，纯文字提示不能提供保证。经用户同意后改用参考图、布局条件或其它控制，并单独记录实验类型。
